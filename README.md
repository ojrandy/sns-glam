# SnS Glam Studio Showcase

Build a premium, fully responsive single-page-app website for **SnS Glams Hair & Makeup Studio**, a luxury hair, makeup and photo studio in Maryland. Static site: no database, no auth.

Three specs are attached and define the whole build, in order — apply all of them:
1. "Build a premium, fully responsive (pasted).md" — the design system, motion, data files, routes, navigation and the full Home page. Note: where it says the booking system comes in the next step, that next step is included below (spec 2), so build the real booking system now instead of a stub.
2. "Add the booking system. (pasted).md" — the global BookingProvider, the single BookingModal ("Get a Quote") with Web3Forms submission, and the reusable submit helper shared with the Contact form.
3. "Build the content pages using the copy below, (pasted).md" — the /about, /faq, /reviews, /blog, /blog/:slug, /contact, /privacy-policy and /disclaimer pages with the exact copy provided.

The three screenshots attached are the design references to blend (Boutique, Luxe Hair Co, Urban Photo Studio), per spec 1. Note on images: no client photo gallery uploads are attached in this conversation — only the 3 design reference screenshots — so populate src/data/gallery.ts with generated on-brand imagery (luxury beauty-editorial photos of Black women: glam makeup, hair installs, studio photoshoots, braiding) matching the categories and featured flags described in spec 1.
